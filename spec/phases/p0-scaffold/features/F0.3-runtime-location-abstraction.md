# F0.3 — Runtime & location abstraction

**Phase:** P0 · **Status:** in-progress · **Owner:** Builder (Go) · **Depends on:** none · **Blocks:** F1.2
**Implements decision:** D2 (isolation ladder)

## Goal
Define the `Runtime` interface and a `location` abstraction so the isolation ladder (`local-docker` / `local-hardened` / `cloud-microvm`) is pluggable from day one — even though only the two local impls exist now.

## Scope
**In:** `Runtime` interface; `RuncRuntime` + `GvisorRuntime` impls (thin, real enough for P1 to build on); `location` enum (`local` | `remote`); tier→runtime resolution.
**Out:** full session lifecycle wiring (F1.2); Kata/Firecracker impls (P6); remote transport (P6).

## Implementation approach
1. **`Runtime` interface** (`internal/session/runtime`), per [architecture.md §6](../../../architecture.md): `Create`, `Exec`, `Destroy`, `Snapshot`.
2. **Impls via Podman:** both `RuncRuntime` and `GvisorRuntime` drive Podman (rootless), differing only in `--runtime` (`runc` vs `runsc`) and the hardening flags. Share a common `podmanRuntime` base; the two are thin configs over it.
3. **Tier resolution:** map policy/config `tier` → concrete `Runtime`:
   - `local-docker` → `RuncRuntime`
   - `local-hardened` → `GvisorRuntime` (default)
   - `cloud-microvm` → `RemoteRuntime` (stub returning `ErrNotImplemented` now)
4. **`location`:** `local` uses the local Podman/runtime; `remote` (stub) will target the cloud gRPC endpoint in P6. Keep the seam clean so P6 is a drop-in.
5. **Capability probe:** detect whether `runsc` is installed/functional; expose `Runtime.Available() error` so callers can fall back with a legible message.

## Tools & libraries
Go, Podman bindings (`containers/podman/v4/pkg/bindings`) or containerd client, gVisor/`runsc` present on host.

## Data structures (Go, indicative)
```go
type Tier string // "local-docker" | "local-hardened" | "cloud-microvm"
type Location string // "local" | "remote"
type SessionSpec struct { Tier Tier; Location Location; ToolchainDigest string; Limits ResourceLimits; /* ... */ }
func ResolveRuntime(t Tier, l Location) (Runtime, error)
```

## Acceptance criteria (testable)
- [ ] `Runtime` interface compiles; `RuncRuntime` and `GvisorRuntime` implement it.
- [ ] `ResolveRuntime("local-hardened","local")` returns a `GvisorRuntime`; `cloud-microvm` returns a stub `ErrNotImplemented`.
- [ ] `Available()` reports a clear error when `runsc` is absent.
- [ ] Both impls share one base with only runtime flag + hardening differences (no duplicated lifecycle logic).

## QA checklist
- [ ] No lifecycle logic duplicated between the two impls.
- [ ] The `remote`/`cloud-microvm` seam is present and cleanly stubbed (no half-wired cloud code).
- [ ] Interface matches architecture.md §6 exactly; any change updated there.

## Security considerations
- Hardening flags (caps drop, no-new-privileges, user-ns remap, read-only rootfs, seccomp) belong to the shared base so they can never be forgotten by one impl. F1.2 asserts them; F0.3 defines where they live.
