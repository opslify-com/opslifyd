# F8.8 — Cockpit UI

**Phase:** P8 · **Status:** planned · **Owner:** Builder (SPA) · **Depends on:** F7.1, F7.4, F8.2, F8.3, F8.4, F8.6, F8.7, F8.10 · **Blocks:**

## Goal
The operator surface: a three-pane cockpit (collapsible project sidebar, tabbed work area, agent panel,
trace drawer) plus the surfaces P8 introduces — Sandboxes, Connections, Secrets, Policy, Instructions,
Changes — all behind the F7.1 launch token and the DNS-rebind Host-guard.

## Scope
**In:** the cockpit shell (sidebar sections collapsible: environment, live sandbox, connections,
skills, **memory**, tools, workspace); a permanent **agent indicator** in the header (which model, transport,
tools, skills); tabbed work area including live SSH/exec sessions; the trace drawer; and the P8
surfaces listed above. Design reference: the published control-tower canvas.
**Out:** new mutations that bypass existing gates — every action routes through the same daemon paths
as the CLI; multi-user presence.

## Acceptance criteria (testable)
- [ ] Every route added here is behind F7.1 token auth **and** the Host-guard (401/403 without), enumerated as in F7.4.
- [ ] No secret value and no raw `/workspace` bytes ever reach the browser (the F3.6 raw-file refusal stays closed).
- [ ] Exec from the cockpit goes through the same F4 classifier and approval path as the CLI — no second exec path.
- [ ] The header agent indicator reflects the bound agent (F8.5) and updates on switch.
- [ ] The sandbox panel shows live isolation facts (tier, caps, egress state, TTL, attached connections) and can kill a sandbox.
- [ ] The SPA remains self-contained (no external asset host) per F3.5/F7.4.
- [ ] A pending approval raises a browser notification from an open cockpit tab, and an `opslify notify` webhook fires when none is open (per D2 — no desktop client).

## QA checklist
- [ ] Enumerate every new `/v1` route: none reachable tokenless or with a foreign Host.
- [ ] Connections/Secrets screens display refs and metadata only; assert no value field is ever populated.
- [ ] Policy edits from the UI create Changes for widening (F8.7) — the UI cannot apply one directly.
- [ ] No regression to F7.1/F7.4 auth, F3.5/F3.6 UI guards.

## Delivery
Localhost SPA served by the daemon; no desktop app, no cloud dependency — see
`spec/decisions/D2-ui-delivery-model.md`. Remote access is an SSH tunnel
(`ssh -L 4646:127.0.0.1:4646 host`), which adds no listener and no code.

## Security considerations
- The cockpit is the widest local surface in the product. Every capability it gains is safe **only**
  because F7.1 gates it; a route added outside the guard is reachable by any local page.
- Showing more must not mean returning more: the UI displays references, hashes and metadata, and the
  daemon remains the only holder of values.
