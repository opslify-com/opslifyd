# SSH fleet — tripon ## Layout - web-01 … web-04 t3.medium, behind ALB tripon-stg-alb - db-01 r6g.large, Postgres 15 primary - Every host is private. Reach them through bastion.tripon.io. ## House rules 1. Always drain a web node before restarting anything on it. aws elbv2 deregister-targets --target-group-arn $TG --targets Id=$ID Wait for the health check to go green before re-adding it. 2. One node at a time. Never restart two web nodes in the same change. 3. db-01 is the primary. No service restarts, no config reloads, no pg_ctl. If it looks like db-01 needs work, stop and ask a human. 4. Prefer systemctl reload over restart when the config allows it — reload keeps connections alive. ## Where things live - nginx config /etc/nginx/conf.d/tripon.conf - app logs journalctl -u tripon-api - deploy dir /srv/tripon ## Diagnosis first 502s on this fleet are almost always memory pressure, not the app. Check free -m and systemctl status nginx before touching anything. Report what you found before proposing a fix. <!-- The agent reads this before it touches the fleet. Anything you write here becomes a rule it follows, not a suggestion it weighs. -->
